# 原生标注编辑器

编辑操作基于已保存的采集，编辑时不联系原应用。发布版 OneShot.app 内置 OneShot Capture 组件；开发版 Editor 与 Probe 仍可分开构建。也可通过[全局快捷键](shortcut-capture.md)委托已授权的采集组件取得新快照，完成后进入相同的编辑流程。

## 一轮使用流程

1. 安装后打开 OneShot；从源码开发时运行 `zsh scripts/build-editor.sh`，打开 `.build/OneShot Editor.app`。
2. 点击“打开”，选择已有采集目录或 `.oneshot` 项目；也可切到目标应用，按 ⌃⌥⌘S 取得新采集。
3. 点击“写反馈”，在固定右栏自由编辑描述。点击“引用控件”临时点选截图上的对象，或输入 `@` 搜索；引用在原光标位置插入，选完可继续输入。同一条反馈可以引用多个控件，也可以不引用任何对象。
4. 原有编号、箭头、方框、文字和“控件”工具继续使用。选择工具可移动普通图形；“标注”页签可修改文字、颜色和线条。“控件树”可搜索、展开并选择节点，再点击“标注此控件”填写独立说明。
5. 点击“交给 Agent”，自动生成固定版本的材料，包含当前截图、每条反馈与标注及冻结 AX 节点，复制 MCP 读取引用。没有标注也可交付整次采集，详见[交付与只读 MCP](agent-handoff.md)。
6. 保存项目后可继续修改。最近采集保留项目入口，重开应用后可继续编辑；导出 PNG 得到原图像素尺寸的合成图片。

工具栏支持撤销／重做；画布选中图形时 Delete 删除、Escape 取消选择。缩放是适应窗口的倍率，放大后可在画布中滚动。普通图形支持移动，第一版尚不提供形状尺寸调整手柄、裁切、涂抹或模糊遮挡。

各类标注均可填写说明。只有控件标注绑定 AX 节点，普通图形通过原图像素坐标表达位置。交付快照包含尚未保存的说明，但导出不代替保存项目；后续修改需要再次交付，生成新的材料版本。

## 反馈描述与控件引用

右侧“反馈”页签与原有图形标注独立。一条描述由有序文字与控件引用组成，允许重复引用同一控件；不同反馈也可以引用同一对象。新增、切换和删除反馈不改变原图或已有标注。侧栏宽度可拖动调整，小窗口中可滚动查看内容。

“引用控件”只开启一次点选：悬停预览目标，点击后自动回到描述中原先的光标位置，Esc 取消并保留草稿。输入 `@` 时就地展示名称／类型搜索候选，上下键选择，Enter 或 Tab 插入，Esc 收起。也可以点击“@ 搜索”直接筛选；无坐标或截图外控件可从列表引用，但不会在图片上伪造定位框。AX 不可用时仍可写纯文字反馈并使用原有图形标注。

描述中的控件是可整体选择和删除的标签，支持原生文字撤销、中文输入法以及复制为可读文本；粘贴的普通文字不会被当成真实控件绑定。点击标签或下方引用列表可在截图中定位；用选择工具点击画面上的 `R` 编号可返回对应反馈。引用编号在整个文档中按节点首次出现顺序生成，真实绑定使用采集身份与节点 ID，不依赖展示编号。

保存 `.oneshot` 项目会同时保存反馈文字、引用顺序及节点关系，旧项目缺少反馈字段时按空列表打开。Agent 交付包含所有引用的完整冻结 AX 节点；标注 PNG 添加 `R1`、`R2` 小标记，与原有编号标注区分。源截图、AX、OCR 和上下文仍保持原始内容。

“最近采集”记录最近 30 份采集或项目。采集成功但暂缓打开时也会记录；打开和保存项目后更新记录。缺失或移动的路径显示为不可用，可仅移除列表记录后重新打开文件。记录文件为 `~/Library/Application Support/OneShot/recent-captures.json`，移除记录不删除截图或项目。

## 控件标注

截图的悬停命中、树中的选择和保存后的节点引用来自同一份 `accessibility.json`。图上优先选择面积较小、层级较深的元素；树视图可选择父节点或其他重叠对象。悬停高亮与已保存标注分开，控件绑定后不能像普通方框那样任意拖动。

AX 使用屏幕坐标，截图使用像素坐标。映射根据冻结的 `screenshot.json` 中窗口边界与实际像素尺寸计算，然后取图片范围内的交集。零面积、屏幕外或定位信息缺失的节点仍保留在树中，可写说明，但不伪造图片上的框。画布上的框仅表示捕获时的边界，不承诺逐像素贴合自绘控件的视觉轮廓。

编辑器只预览节点的角色与简短名称；完整属性、富文本和诊断仍保存在原始 AX 文件。节点 ID 仅在当前捕获中有意义，不作为跨次采集的稳定标识。AX 不可用时，图形标注仍可使用。

参考的交互是官方浏览器文档中的 Annotate、点击元素／框选区域、添加评论流程；官方扩展说明也采用 ID、角色、边界，以及分开的悬停／选中状态。OneShot 借鉴这个交互和数据关系，通过本机 AppKit 实现，不调用 Codex 内部服务。

- [Browser：Comment on the page](https://learn.chatgpt.com/docs/browser#comment-on-the-page)
- [Annotations extensibility：Canvas objects](https://learn.chatgpt.com/docs/annotations-extensibility#make-canvas-objects-selectable)

## 文件与保存

```text
example.oneshot/
  annotations.json
  capture/
    manifest.json
    screenshot.png
    screenshot.json
    accessibility.json
    context.txt
    ocr.json
    …该捕获的其他原始文件
```

项目首次保存复制整个采集目录的常规文件，即使没有任何标注，也保留完整上下文。以后保存只更新标注 JSON。项目重开核对捕获 ID、原始图片实际尺寸及控件节点存在性；原图和原始上下文不随编辑改变。文件采用私有权限，原始采集、符号链接和已有导出目标不会被覆盖。

导出 PNG 画出普通图形以及有可见边界的控件框和编号。控件长说明保留在标注数据中，不自动覆盖截图正文；只有 PNG 无法恢复完整说明或 AX 上下文。
