# 原生标注编辑器

编辑操作基于已保存的采集。OneShot Editor 与采集用 Probe 分开构建，编辑时不联系原应用。现在也可通过[全局快捷键](shortcut-capture.md)委托已授权的 Probe 取得新快照，完成后进入相同的编辑流程。

## 一轮使用流程

1. 运行 `zsh scripts/build-editor.sh`，打开 `.build/OneShot Editor.app`。
2. 点击“打开”，选择已有采集目录或 `.oneshot` 项目；也可切到目标应用，按 ⌃⌥⌘S 取得新采集。
3. 在截图上添加编号、箭头、方框、文字；选择工具可移动图形，侧栏可修改文字、颜色和线条。
4. 使用“控件”工具点选截图上的 AX 元素，或切到“控件树”搜索、展开并选中节点。点击“标注此控件”后，在右侧填写说明。
5. 保存项目后可继续修改。导出 PNG 得到原图像素尺寸的合成图片；节点说明及完整上下文在项目中保留。

工具栏支持撤销／重做；画布选中图形时 Delete 删除、Escape 取消选择。缩放是适应窗口的倍率，放大后可在画布中滚动。普通图形支持移动，第一版尚不提供形状尺寸调整手柄、裁切、涂抹或模糊遮挡。

## 控件标注

截图的悬停命中、树中的选择和保存后的节点引用来自同一份 `accessibility.json`。图上优先选择面积较小、层级较深的元素；树视图可选择父节点或其他重叠对象。悬停高亮与已保存标注分开，控件绑定后不能像普通方框那样任意拖动。

AX 使用屏幕坐标，截图使用像素坐标。映射根据冻结的 `screenshot.json` 中窗口边界与实际像素尺寸计算，然后取图片范围内的交集。零面积、屏幕外或定位信息缺失的节点仍保留在树中，可写说明，但不伪造图片上的框。画布上的框仅表示捕获时的边界，不承诺逐像素贴合自绘控件的视觉轮廓。

编辑器只预览节点的角色与简短名称；完整属性、富文本和诊断仍保存在原始 AX 文件。节点 ID 仅在当前捕获中有意义，不作为跨次采集的稳定标识。AX 不可用时，图形标注仍可使用。

参考的交互是官方浏览器文档中的 Annotate、点击元素／框选区域、添加评论流程；官方扩展说明也采用 ID、角色、边界，以及分开的悬停／选中状态。OneShot 借鉴这个交互和数据关系，通过本机 AppKit 实现，不调用 Codex 内部服务。

- [Browser：Comment on the page](https://learn.chatgpt.com/docs/browser#comment-on-the-page)
- [Annotations extensibility：Canvas objects](https://learn.chatgpt.com/docs/annotations-extensibility#make-canvas-objects-selectable)

## 文件与保存

```text
example.oneshot/
  annotations.json
  capture/
    manifest.json
    screenshot.png
    screenshot.json
    accessibility.json
    context.txt
    ocr.json
    …该捕获的其他原始文件
```

项目首次保存复制整个采集目录的常规文件，即使没有任何标注，也保留完整上下文。以后保存只更新标注 JSON。项目重开核对捕获 ID、原始图片实际尺寸及控件节点存在性；原图和原始上下文不随编辑改变。文件采用私有权限，原始采集、符号链接和已有导出目标不会被覆盖。

导出 PNG 画出普通图形以及有可见边界的控件框和编号。控件长说明保留在标注数据中，不自动覆盖截图正文；只有 PNG 无法恢复完整说明或 AX 上下文。

## 验证入口

2026-10-25 执行 `zsh scripts/test.sh`，32 项测试通过。新增覆盖保存重开、移动项目后离线读取、源文件不变、错误绑定与伪造节点框拒绝、像素坐标转换、无图上坐标的节点、导出方向、中文及图形绘制、已有目标保护。

原生窗口使用音乐的已保存采集完成以下实测：

- 打开 2430 × 1424 原图；载入 119 个 AX 节点，117 个有图上边界。原采集的部分属性读取失败状态继续显示，不因此宣称 AX 完整。
- 添加编号、箭头、方框、中文文字；在 200% 缩放下移动编号并撤销。
- 直接点击截图上的播放按钮，绑定 `AXButton / n78`；搜索控件树中的专辑标题 `AXStaticText / n71`，选中后截图同步高亮，再添加独立中文说明。
- 修复并复测从截图移入侧栏后的悬停清理，以及画布上的 ⌘Z／⇧⌘Z。删除控件标注、撤销恢复、重做删除均可操作。
- 保存含 6 条标注的项目，退出并重新打开；两条控件说明、节点 ID 和位置保留。实际导出 PNG 为 2430 × 1424，图像方向与标注位置正确。
- 原采集及项目副本中的截图、AX、OCR、上下文、截图元数据与 manifest 共 6 个文件，SHA-256 均与编辑前一致。已授权 Probe 的签名摘要未变化。

测试日志、示例项目和导出图片保存在本机 `LocalEvidence/editor-mvp/`，不纳入 Git。以上实测证明音乐样本的编辑闭环；OpenSurge 和 Cursor 的原生编辑交互尚未逐应用重跑，跨次捕获重新定位和 Agent 交付不在该轮验收中。后续快捷键采集入口及其独立验证记录见[快捷键采集](shortcut-capture.md)。
