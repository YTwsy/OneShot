# OneShot 0.1.0 · build 12

OneShot 把窗口截图、你的反馈和已采集的界面上下文一起交给 Agent。本版是首个公开的正式 Release，支持 **macOS 14+、Apple Silicon（arm64）**，采用 MIT License。

## 主要功能

- **快捷采集与标注。** 使用 ⌃⌥⌘S 或倒计时采集当前窗口，添加编号、箭头、方框、文字，并保存为可继续编辑的 `.oneshot` 项目。
- **把反馈指向控件。** 在截图中点选或输入 `@` 搜索，将多个控件引用写进同一句话；`R1`、`R2` 与画面双向定位。
- **连接 Agent。** 一键配置 Codex / Claude Code 用户级 MCP，保留配置备份并检测并发修改；也支持导出 Agent 文件夹。
- **明确交付固定版本。** “交给 Agent”创建材料版本并复制引用，粘贴到对话后由 Agent 读取。后续交付生成新版本，旧引用保持不变。
- **保留上下文与读取边界。** 只读 MCP 提供反馈、标注图、原图、冻结 AX 节点与截图／AX／OCR 状态，支持详情分页、局部图片及撤销后续读取。
- **单个 App。** 内置采集组件与 MCP，提供权限引导、最近采集及晚到结果恢复；安装包用户不需要 Swift 工具链。

## 从 build 11 升级

本版基于上一版功能，通过 GitHub Actions 重新构建，正式版本号、包内渠道、标签与发布清单统一为 `0.1.0` / `v0.1.0`。构建使用 build 11 作为基线，三个组件必须互相满足新旧代码身份要求，才会输出安装包；结果见 `identity-compatibility.json`。

这是签名身份检查，**不等于已验证用户 Mac 上的屏幕录制或辅助功能授权保持**。请退出旧版后将新 App 替换到相同安装位置，实际采集并检查权限状态。当前采用手动下载替换更新。

## 下载与安装

下载 `OneShot-0.1.0-macos-arm64-apple-development-unnotarized.dmg`，核对同名 `.sha256` 文件后，将 `OneShot.app` 拖到 Applications。

本版使用 **Apple Development 签名，未经 Apple 公证，无 Developer ID 分发签名**。正式 Release 标记不改变上述状态。macOS 可能阻止首次打开，请按 [Apple 的应用打开说明](https://support.apple.com/guide/mac-help/open-a-mac-app-from-an-unknown-developer-mh40616/mac)处理，不要关闭整机安全检查。

首次采集需要在系统设置中批准屏幕录制与辅助功能权限。从 ad-hoc 包迁移可能需要重新确认权限。安装和权限步骤见[使用指南](https://github.com/YTwsy/OneShot/blob/main/docs/getting-started.md)。

## 验证与能力边界

发布工作流运行 Swift 测试、打包与签名工具测试、临时身份签名集成测试，并检查 arm64 架构、macOS 部署目标、三个组件的签名、版本与源码提交。正式产物附带源码归档、SHA-256、签名报告、构建清单和身份兼容报告。

下载后的首次打开、首次授权、实际升级权限保持、连续快捷键采集、未保存编辑期间的新采集和 HUD 焦点仍需用户 Mac 验证。自动检查不能代替这些操作。

材料保留在本地，只有明确交付的快照进入 MCP 材料库；OneShot 不自动发送 Agent 消息或上传材料。Agent 读取后的处理由该客户端决定，撤销无法收回已经读取的内容。分享前请检查整次采集，包括未标注区域和 AX／OCR 文本。截图、AX 与 OCR 分别采集，不保证原子一致或完整文档；当前没有裁切或模糊遮挡工具。
