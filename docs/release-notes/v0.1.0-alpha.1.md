# OneShot 0.1.0-alpha.1 · build 11

OneShot 把应用截图、反馈、控件引用与已采集的界面上下文一起交给 Agent。本版为 macOS 14+、Apple Silicon（arm64）的首个 GitHub Actions 私有预发布构建，使用 MIT License。

## 本版包含

- ⌃⌥⌘S 或倒计时采集当前应用窗口，进入原生标注编辑器。
- 固定反馈侧栏支持自由描述，通过点选或 `@` 搜索在同一句话中引用多个控件，`R1`、`R2` 与截图双向定位。
- 保留编号、箭头、方框、文字和控件标注；普通图形保存原图像素坐标。
- 一键连接 Codex / Claude Code 用户级 MCP，配置更新保留原文件备份并检测并发修改。
- “交给 Agent”创建固定版本并复制材料引用；粘贴给 Agent 后读取反馈、标注图、冻结控件与采集状态。再次交付递增版本，旧引用不变。
- 内置只读 MCP 支持持续材料库、详情分页与局部图像；可在交付历史撤销后续读取，保留兼容文件夹导出。
- 可继续编辑的项目、最近采集、晚到结果恢复、采集反馈与阶段计时。
- 单个 App 内置采集组件，提供权限检查和明确的授权入口。
- 首次启动展示权限引导，分别开启屏幕录制与辅助功能；支持跳过设置先编辑已有材料，以及返回设置后的自动复查。
- 中英文 README、安装说明和使用虚构数据的两张流程动态图。

## 安装与状态

下载 DMG，将 `OneShot.app` 拖到 Applications。本版使用 **Apple Development 签名，无 Developer ID 分发签名，未经 Apple 公证**，仅用于预发布测试。macOS 可能阻止首次打开；请核对下载来源和 SHA-256 后按系统提示决定是否允许。不要关闭整机安全检查。

截图与 AX 需要用户在系统设置中批准 OneShot 采集组件的屏幕录制和辅助功能权限。从 ad-hoc 包升级可能需要重新确认权限。复用同一证书仍需实机验证权限保持，首次 GitHub 构建没有前一次 CI 构建作为升级基线。此版本不包含自动更新，后续版本采用手动替换 App。

材料默认保留在本地。OneShot 不自动发送 Agent 消息或上传材料；连接后将引用粘贴给 Agent，其后续数据处理由该客户端决定。未交付草稿不进入材料库，已读取内容无法通过撤销收回。

## 验证与限制

自动测试覆盖采集目标与回执核验、标注保存／移动／重开、AX 坐标映射、导出绑定与源文件保护、最近项目恢复、晚到采集恢复，以及 MCP 路径范围、中文分页、图片与持续 stdio 交互。

此前已实测“截图上点选按钮 → 填写中文意见 → 导出 → MCP 读取对应 AX 节点与图片”，以及保存项目后重开应用恢复编辑。这些属于功能验证，不等于本发布包已通过所有下载／安装／授权场景。

真实快捷键连续采集、未保存标注期间的新采集、关闭窗口后快捷键、HUD 实际焦点行为、首次下载运行和升级后的采集授权仍需实机复测。具体完成情况以随发布提供的验证记录为准。

采集只保留应用实际暴露的信息；AX／OCR 失败和预算限制明确记录，不保证完整文档。截图与 AX 分别读取，不保证内容原子一致。分享材料前请检查整次采集。
