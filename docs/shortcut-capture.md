# 快捷键采集

打开 OneShot Editor 并保持运行，切到目标应用，按 **Control + Option + Command + S（⌃⌥⌘S）**。程序先确定前台应用及窗口，再调用已授权的 OneShot Probe；截图与上下文保存完成后打开标注界面。

## 使用与窗口选择

- 选择按键发生时前台应用最靠前的可见普通窗口。应用有多个窗口时只捕获这一扇，不承诺它等同于 AX 的 focused window，也不扩大到全部窗口。
- OneShot Editor 和 Probe 本身不作为目标。应用已退出、没有可用窗口或身份发生变化时报告原因，不改选其他应用。
- 菜单栏与编辑器提供“3 秒后采集”；启动倒计时会隐藏编辑器，在倒计时结束时读取当前前台应用。菜单栏可取消倒计时。
- 关闭编辑窗口后应用继续运行，菜单栏和快捷键保留；⌘Q 退出应用并注销快捷键。快捷键注册冲突会显示错误，可在采集设置中重新启用。
- 已有未保存标注、正在显示模态窗口或采集期间切换了项目时，新结果保存为“待打开”，由用户随后打开。不会直接覆盖当前编辑内容。

默认采集位置为 `~/Library/Application Support/OneShot/Captures`，可从“采集设置 → 打开采集目录”访问。每次采集使用独立目录；运行记录放在其下的 `.runs`，原始采集含 `trigger.json`，记录触发时间、应用 PID、bundle ID、窗口 ID 和选择依据。

## 采集组件与完成判定

发布版 `OneShot.app` 默认使用内置的 `Contents/Helpers/OneShot Capture.app`，不沿用开发版保存的外部 Probe 路径。当前开发版默认连接编辑器同目录的 `OneShot Probe.app`，也可在设置中选择已有组件。编辑器通过 LaunchServices 正常启动指定 bundle，显式关闭自动激活与其他运行实例替代；采集前不把编辑器带到前台。完成后才显示编辑窗口。开发编辑器升级不重建、不重新签名已经授权的开发 Probe。

采集仍由 Probe 的辅助功能和屏幕录制权限承担，编辑器不复制其他应用的权限。快捷键入口不自动更改目标应用的辅助功能模式、不滚动或点击目标内容。

发布版提供“检查采集权限”和“授权采集组件”入口。检查由实际内置组件报告权限，不会主动请求授权；授权入口显式启动 macOS 提示，最终由用户在系统设置中批准。使用旧开发 Probe 时仍可采集，但新增的 GUI 权限报告需要包含 `doctor --output` 支持的新版组件。

启动回调仅表示启动情况。编辑器等待独立的完成回执，并核对 manifest 的应用、PID、窗口 ID 和实际图片，再打开结果。截图可用但 AX 或 OCR 部分失败时保留截图并显示提示，不将进程退出成功解释为信息完整。

采集忙碌时不重复启动；默认最多等待 120 秒。超时保留运行记录，不终止 Probe、不自动重试。后续请求须先确认原采集完成或进程退出；重开编辑器后如发现 Probe 仍在运行，同样拒绝重叠启动。启动编辑器、再次采集前或使用“检查已完成的采集”时，会验证最近最多 128 份运行记录，找回已有有效回执、身份一致且含可用截图的结果。结果写入最近列表后才标记已交付；失败或状态未知的运行继续保留记录。

开发验证可通过绝对路径参数指定 `--probe-app` 与 `--capture-root`，普通使用无需这些参数。

## 等待反馈与分段计时

快捷键入口先请求显示不激活应用的浮动提示，再识别目标并启动 Probe；采集中菜单栏也显示忙碌状态。提示不接收鼠标事件或键盘焦点。只有回执、目标身份和图片校验结束后才打开编辑器，AX 读取期间不会提前弹出编辑窗口。新版 Probe 报告启动、截图、AX、OCR、保存进度；OCR 仍在 AX 完成后读取冻结图片，本轮未改变串行顺序。

- 新版 CLI 的采集目录含 `timings.json`：各阶段的单调时钟毫秒耗时和状态；失败／未请求／不可用的组件也有记录。
- `.runs/<运行 ID>/service-timings.json`：LaunchServices 回调延迟、回执观测、结果校验和服务总耗时。回调延迟不是精确的进程启动时间，回执观测包含最多约 200 ms 的轮询间隔。
- `.runs/<运行 ID>/editor/timings.json`：反馈请求、目标识别、编辑器载入、显示请求以及触发至显示请求耗时。显示请求计时不代表系统合成器确认的首帧；待打开结果不虚构编辑器载入耗时。
- `.runs/<运行 ID>/receipt.json.progress.json`：新版 Probe 的临时进度，绑定启动进程与最终采集 ID。它不修改原始完成回执。

CLI 的 `startup` 从主入口计至参数、目标、输出目录及可选准备完成。截图／AX／OCR 段包含各自的序列化和写盘；编辑器载入包含项目、图片、控件索引与最近列表持久化。反馈请求也仅计至 HUD 同步调用返回，不是首帧测量。

编辑器兼容已授权的旧 Probe，不传入其不支持的新参数。旧 Probe 没有上述采集分段数据时，界面明确显示未知，不用约 7 秒的总耗时推算各组件耗时。本轮未重建或重新签名固定 Probe；升级 Probe 后可能需要重新检查系统授权，因此没有自动替换它。

本轮新增行为的自动测试和边界见[交付验收](agent-handoff.md)。连续真实按键、关闭编辑窗口后再次快捷键、脏项目期间新采集及浮动提示的实际焦点行为仍待实机复测；自动化工具的应用内键盘事件未触发全局快捷键，不能计为通过。
