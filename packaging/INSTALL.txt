OneShot Preview — macOS 14+ / Apple Silicon

Install
1. Drag OneShot.app to Applications.
2. Eject this disk image, then open /Applications/OneShot.app.
3. Follow the permission guide. Capture requires Screen Recording and
   Accessibility approval for OneShot's bundled capture component.
   The app and its capture component both use the display name OneShot.
   macOS may retain older entries named OneShot Capture; identify the current
   component using the path shown in the permission guide.

This preview has NOT been notarized by Apple. The About window and accompanying
release-manifest.json identify the signing mode of this particular build:
self-signed, Apple Development, Developer ID, or explicitly selected ad-hoc.
A certificate signature alone does not mean Apple notarization or Gatekeeper
acceptance. Review macOS security prompts and the release information.
Do not disable Gatekeeper or other system protections.

Updates are manual: quit OneShot, replace /Applications/OneShot.app, then reopen.
Certificate builds are intended to reuse a compatible code identity. Permission
retention must still be checked by an actual capture after upgrading. Moving
from an ad-hoc build to a certificate build may require authorization once.
An ad-hoc build does not provide a stable code identity across changing builds.

Captures, annotations and Agent handoff are stored locally. Exporting material
does not send it to a remote service. Review captures before sharing them.

MCP command after installation:
  /Applications/OneShot.app/Contents/Helpers/oneshot-mcp
Arguments:
  --handoff /absolute/path/to/one-export
