OneShot Preview — macOS 14+ / Apple Silicon

Install
1. Drag OneShot.app to Applications.
2. Eject this disk image, then open /Applications/OneShot.app.
3. Review the first-run permission guide. Capture requires Screen Recording and
   Accessibility approval for the bundled OneShot Capture component.

This preview is ad-hoc signed and has NOT been notarized by Apple. It has no
Developer ID signature. macOS may block the downloaded application. Review the
system's security prompts and the project's release information before opening.
Do not disable Gatekeeper or other system protections.

Capture, annotations and Agent handoff are stored locally. Exporting material
does not send it to a remote service. Review captures before sharing them.

MCP command after installation:
  /Applications/OneShot.app/Contents/Helpers/oneshot-mcp
Arguments:
  --handoff /absolute/path/to/one-export

Updates in this preview are manual: quit OneShot, download a newer release, and
replace the application. Recheck macOS permissions after replacement; ad-hoc
signatures do not provide a stable Developer ID identity across builds.
